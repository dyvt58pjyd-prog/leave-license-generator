# Maharashtra Leave & License Agreement Generator 📄

A React and Vite web application for drafting, customizing, and printing legally balanced Leave & License Agreements in accordance with Section 55 of the Maharashtra Rent Control Act, 1999 and the Indian Easements Act, 1882.

## Features

- **Multi-language Templates:** Generate legally binding agreements in **Marathi (मराठी)**, **Hindi (हिंदी)**, and **English**.
- **Co-Licensee Support:** Add primary and joint licensees (e.g., Deep Sunil Sapkal & Gauravsingh Darshansingh Thakur).
- **Pro-Licensee Legal Protections:**
  - Mandatory refund of security deposit within 7–10 days of possession handover.
  - Balanced late payment penalties with 7-day grace period.
  - 6-month lock-in period and 60-day mutual notice period.
  - Express right to install and remove commercial fixtures/machinery (gym equipment, rubber mats, mirrors, ACs).
  - First right of refusal on renewal with rent escalation caps.
  - 3-Phase commercial power warranty and owner's NOC guarantee.
  - 24-hour prior written appointment for inspections to ensure patron privacy.
- **A4 Direct Print & PDF Export:** Cleanly formatted for A4 page output with exact millimeter margins and physical Government Stamp Paper margin support.
- **Auto Date & Number-to-Words Calculation:** Automatic date math and Indian currency conversion to words in English, Devanagari Marathi, and Hindi.

## Tech Stack

- **React 19**
- **Vite 6**
- **Tailwind CSS 4**
- **Lucide React** (Icons)
- **html2pdf.js** (PDF export)

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
```
